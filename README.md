# Sales & Inventory Management System

## Quick Start

### On Windows:
1. Double-click `build_windows.bat` to build the .exe
2. Find your app in `dist/Sales & Inventory Management System.exe`

### On Linux (for testing):
```bash
python3 main.py
```

## Building for Windows

```batch
build_windows.bat
```

The .exe will be in the `dist/` folder.

## Features
- Multi-item sales
- Customer management (edit, delete, pay debt, adjust debt)
- Inventory tracking
- Daily reports & analytics
- Receipt generation
- Low stock alerts

## Requirements
- Python 3.7+
- See `requirements.txt`

## Notes
- First launch may take 15-20 seconds (Windows antivirus scan)
- Icon: Blue-green gradient with MCF logo
- Standalone .exe includes all dependencies
